Initial public code and results release for *Perturbation structure and imperfect physics in neural PDE forecasting*.

Includes exact source snapshots and archived evidence for 864 development fits and 720 follow-up fits, spanning eight synthetic PDE systems and three neural architectures. The follow-up covers spatial-resolution checks and a frozen augmentation selector on Cahn–Hilliard and FitzHugh–Nagumo.

Selected resolution effects support both benefits and harms from physical guidance. The guarded selector improves on short-probe selection in the primary pooled analysis; its comparison with no augmentation is inconclusive. Documentation includes the statistical scope and secondary limitations.

This release provides configuration files, protocols, per-candidate records, evaluation arrays, reports, integrity checks, a Jupyter result viewer, and reproduction instructions. Training trajectories and model checkpoints are regenerated by the source runners. No new model training was performed to prepare this GitHub package.
